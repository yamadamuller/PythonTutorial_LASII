# Running the notebooks
First clone this repository on your machine:

```
cd <desired_path>
git clone https://github.com/yamadamuller/PythonTutorial_LASII.git
cd PythonTutorial_LASII
```

Then, configure a Python environment. The framework has been successfully tested in Python 3.13. Also, in both Linux and Windows operating systems. Lastly, install the required packages listed in the requirements text file at the root of the repository with:

```
pip install -r requirements.txt
```

Once all packages are installed, the notebooks are ready for use. Start a Jupyter Notebook server in yout local machine with:
```
jupyter notebook
```

Access it at the address http://localhost:8888/tree, if it does not launch automatically.
